# AZ-305 abbreviation glossary

Use this page for quick recall. Each study file still expands important abbreviations at its first meaningful occurrence.

| Abbreviation | Full term | Exam meaning |
|---|---|---|
| ACL | Access control list | Permissions applied to an object such as a file or directory |
| AD DS | Active Directory Domain Services | Self-managed directory and domain services |
| ADLS Gen2 | Azure Data Lake Storage Gen2 | Blob Storage with hierarchical namespace for analytics |
| ADF | Azure Data Factory | Data movement and pipeline orchestration service |
| ACI | Azure Container Instances | Direct container-group execution without an orchestrator |
| AKS | Azure Kubernetes Service | Managed Kubernetes platform |
| AMA | Azure Monitor Agent | Guest operating-system telemetry collector |
| API | Application programming interface | Programmatic service contract or endpoint |
| APIM | Azure API Management | API gateway, policy, and developer-management platform |
| AVD | Azure Virtual Desktop | Cloud-hosted desktops and remote applications |
| ARM | Azure Resource Manager | Azure control-plane deployment and management service |
| ASR | Azure Site Recovery | Workload replication, failover, and disaster recovery service |
| BGP | Border Gateway Protocol | Dynamic route exchange used by hybrid connectivity |
| B2B | Business-to-business | External partner collaboration with workforce resources |
| B2C | Business-to-consumer | Legacy product/scenario term for customer identity; use current External ID terminology for new designs |
| CAF | Microsoft Cloud Adoption Framework for Azure | Guidance for cloud adoption and operating-model decisions |
| CI/CD | Continuous integration and continuous delivery | Automated build, validation, and release practices |
| CIAM | Customer identity and access management | Identity for customer-facing applications |
| DCR | Data Collection Rule | Azure Monitor collection and routing configuration |
| DDoS | Distributed denial of service | Volumetric network attack category |
| DLQ | Dead-letter queue | Holding area for messages that cannot be processed or delivered |
| DMS | Azure Database Migration Service | Supported online and offline database migration service |
| DNAT | Destination network address translation | Translates a destination address, commonly for published inbound flows |
| DNS | Domain Name System | Maps names to endpoints and addresses |
| DR | Disaster recovery | Restore service after a major site or region failure |
| ELT | Extract, load, transform | Load data before transforming it with target-platform compute |
| ETL | Extract, transform, load | Transform data before loading it into the serving target |
| FCI | Failover cluster instance | SQL Server instance-level high-availability pattern |
| FIDO2 | Fast Identity Online 2 | Standard used by phishing-resistant security keys/passkeys |
| FQDN | Fully qualified domain name | Complete DNS name for a host or service |
| GA | Generally available | Released for supported production use, subject to service terms |
| GRS | Geo-redundant storage | Locally redundant primary plus asynchronous secondary region |
| GZRS | Geo-zone-redundant storage | Zone-redundant primary plus asynchronous secondary region |
| HA | High availability | Continue service through expected local failures |
| HADR | High availability and disaster recovery | Combined database availability and recovery design area |
| HDD | Hard disk drive | Magnetic disk storage tier suited to low-cost, latency-tolerant workloads |
| HNS | Hierarchical namespace | Directory semantics enabled for ADLS Gen2 |
| HSM | Hardware security module | Protected cryptographic-key processing hardware |
| IaaS | Infrastructure as a service | Customer manages guest operating system through application |
| IaC | Infrastructure as code | Declarative, versioned deployment of infrastructure |
| IOPS | Input/output operations per second | Storage performance measurement |
| ITSM | IT service management | Operational incident/change/service-management integration |
| KQL | Kusto Query Language | Query language used by Azure Monitor Logs and related services |
| LRS | Locally redundant storage | Copies within one physical location in a region |
| LTR | Long-term retention | Extended database backup retention |
| LDAP | Lightweight Directory Access Protocol | Directory query/authentication protocol used by compatible legacy workloads |
| MFA | Multifactor authentication | Authentication requiring more than one form of evidence |
| NAT | Network address translation | Maps one network address space to another |
| NFS | Network File System | File-sharing protocol commonly used by Linux/Unix workloads |
| NIC | Network interface card | Azure resource/interface that connects compute or a private endpoint to a network |
| NSG | Network security group | Stateful Layer 3/Layer 4 filtering on Azure subnets or interfaces |
| NVA | Network virtual appliance | Software network function running as a virtual appliance |
| OIDC | OpenID Connect | Authentication layer built on OAuth 2.0 |
| OLTP | Online transaction processing | Operational transactional database workload |
| PaaS | Platform as a service | Azure manages infrastructure and service platform/runtime |
| PIM | Microsoft Entra Privileged Identity Management | Eligible, time-bound privileged access |
| PITR | Point-in-time restore | Restore data to a selected historical point |
| PHS | Password hash synchronization | Hybrid sign-in method that authenticates in Microsoft Entra ID using synchronized password hashes |
| PTA | Pass-through authentication | Hybrid sign-in method that validates passwords through on-premises agents |
| RA-GRS | Read-access geo-redundant storage | GRS with read access to the secondary region |
| RA-GZRS | Read-access geo-zone-redundant storage | GZRS with read access to the secondary region |
| RBAC | Role-based access control | Authorization through roles assigned at scopes |
| RPO | Recovery point objective | Maximum acceptable data-loss window |
| RTO | Recovery time objective | Maximum acceptable recovery time |
| RU | Request unit | Azure Cosmos DB normalized throughput measure |
| SaaS | Software as a service | Provider operates the complete application platform |
| SAML | Security Assertion Markup Language | Federation protocol for exchanging authentication assertions |
| SAS | Shared access signature | Time- and permission-bounded delegated Storage access |
| SIEM | Security information and event management | Security-event collection, correlation, and investigation |
| SLA | Service-level agreement | Provider commitment for a defined service metric |
| SMB | Server Message Block | Network file-sharing protocol |
| SNAT | Source network address translation | Translates source addresses for outbound connections |
| SOAR | Security orchestration, automation, and response | Automated security investigation and response workflows |
| SSO | Single sign-on | Authenticate once to access multiple trusted applications |
| TDE | Transparent Data Encryption | Database file, log, and backup encryption at rest |
| TLS | Transport Layer Security | Encryption and authentication for data in transit |
| UDR | User-defined route | Customer-configured Azure route used to override or steer traffic |
| VM | Virtual machine | Software-defined computer with customer-managed guest OS |
| VMSS | Virtual Machine Scale Sets | Model-managed fleet of similar Azure VMs |
| VDI | Virtual desktop infrastructure | Centrally hosted desktop and application delivery model |
| VNet | Azure Virtual Network | Private Azure network and addressing boundary |
| VPN | Virtual private network | Encrypted network tunnel over a shared network |
| WAF | Web Application Firewall | Layer 7 HTTP(S) attack filtering |
| WORM | Write once, read many | Immutable retention model |
| ZRS | Zone-redundant storage | Synchronous copies across availability zones in one region |

In this guide, **WAF** means Web Application Firewall only. The Azure Well-Architected Framework is written out to avoid abbreviation ambiguity.
